## Color palette

| Role | Name | HEX |
|------|------|-----|
| Primary | Purple | `#645faa` |
| Accent | Magenta | `#862d91` |
| Background dark | Dark | `#131120` |
| Background light | White | `#FFFFFF` |

Signature gradient: `linear-gradient(135deg, #645faa 0%, #862d91 100%)`

Secondary (use sparingly, max 3 brand colors in any composition):
Red `#D6413A` · Pink `#DE607D` · Magenta2 `#C94895` · Purple2 `#7A4294` · Periwinkle `#626AB1` · Light Blue `#6BA3D7` · Coral `#E17B62` · Peach `#EEA172`

**Do NOT use `#6C63FF`** — frequently mistaken as brand purple, it's not.

## Typography

- **Display / headlines:** Euclid Flex (Thin → Bold, with italics)
- **Body / UI:** Gotham (Light → Black)
- **Body base:** 16px / 400 weight / 1.6 line-height
- Never substitute Inter, SF Pro, Roboto or other system fonts in brand materials.
- Self-host via `@font-face`; do not load from Google Fonts.

## Logo rules

- Wordmark aspect ratio: ~4:1, never distort
- Minimum sizes: wordmark 80px wide, icon 16px
- Clear space: at least 16px on all sides
- Color variant: on white or warm-dark; white variant: on dark only
- No drop shadow, outline, gradient overlay, or rotation

## Voice

- Confident, direct, friendly-cool — "playful but pro"
- RO: informal but professional ("să rezervăm", not "rezervați vă rugăm")
- EN: premium, sophisticated, international — never over-formal
- Signature phrases: *We IMAGINE → We CREATE → We IMPLEMENT* · *Don't chase, attract* · *...and more to come — let's get connected!*
- No emoji in default UI/marketing copy
