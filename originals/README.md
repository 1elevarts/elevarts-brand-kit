# Elevarts Brand Folder

This folder is Claude's reference for all Elevarts brand assets.
Drop files into the appropriate subfolder and Claude will use them in future sessions.

## Folder Structure

| Folder | What to put here |
|--------|-----------------|
| `logos/` | SVG, PNG logo files (all variants: dark, light, icon only) |
| `brand-book/` | Brand book PDF |
| `catalogues/` | Product/service catalogues (PDF, images) |
| `characters/` | Character/mascot photos or illustrations |
| `photos/` | General brand photography, team photos, office photos |

## Brand Quick Reference

- **Colors**: see [colors.md](colors.md)
- **Fonts**: see [fonts.md](fonts.md)
